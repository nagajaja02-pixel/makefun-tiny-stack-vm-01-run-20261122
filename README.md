A tiny stack virtual machine: one program (`main.ts`, Node 22, stdlib only) that runs every instance of make.fun's tiny stack ISA — 40 bytecode programs, byte-exact stdout and correct exit codes.

## Run it

```
MAKEFUN_INPUT_DIR=practice/input MAKEFUN_OUTPUT_DIR=out node main.ts
```
